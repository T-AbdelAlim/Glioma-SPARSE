# Glioma-SPARSE

Selective Patch Analysis for Resource-efficient Subtype Estimation

A hierarchical weakly supervised deep learning framework for glioma grade and
molecular subtype classification from routine H&E whole-slide images. Designed
to operate efficiently on low-resolution slide representations, with spatially
interpretable predictions.

## Status

Under development.

## Installation

```bash
git clone https://github.com/T-AbdelAlim/Glioma-SPARSE.git
cd Glioma-SPARSE
conda env create -f environment.yml
conda activate glioma-sparse
```
